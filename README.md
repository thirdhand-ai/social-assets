# social-assets
Public image host + tooling for the @thirdhandai Instagram system.
- `YYYY-MM/postN-slide-K.jpg`: published slide images (Metricool pulls these by raw URL)
- `content-log.md`: every post, status, hashtags, unused ideas. Check before proposing anything.
- `tools/render.js`: HTML to JPEG renderer (1080x1350)
- `tools/examples/`: working slide generators (python writes HTML; render.js shoots it)
- `tools/logos/`: logos and founder photo
Image URL format: https://raw.githubusercontent.com/thirdhand-ai/social-assets/main/<path>
